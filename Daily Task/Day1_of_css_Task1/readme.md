# Day 1 - CSS Daily Task

## College Application Form

This is my first CSS Daily Task project. In this task, I created a simple and structured College Application Form using HTML and CSS.

## About the Project

The College Application Form is designed to collect basic student information required for a college application. The form includes different fields for entering personal, academic, and contact details.

CSS is used to style the form and make the overall layout clean, organized, and user-friendly.

## Technologies Used

* HTML5
* CSS3

## Features

* Simple college application form
* Student personal information section
* Contact information fields
* Academic information fields
* Different types of form inputs
* Proper alignment and spacing
* CSS styling for form elements
* Clean and organized layout
* Easy-to-use form structure

## CSS Concepts Practiced

* Basic selectors
* Colors and backgrounds
* Font styling
* Text alignment
* Width and height
* Margin and padding
* Borders
* Border radius
* Form element styling
* Input field styling
* Button styling
* Basic layout and positioning

## Learning Outcome

Through this task, I learned how to apply CSS styles to HTML elements and form components.

I practiced creating a structured layout and improving the appearance of a basic HTML form using CSS.

This task helped me understand how HTML provides the structure of a webpage while CSS is used to control its design and presentation.
