# Day 4 – CSS Task 4: NAB

## 📌 Project Overview

This is my **Day 4 CSS Task**, created using HTML and CSS.

The webpage is based on **NAB (National Australia Bank)**, a banking-themed interface designed to practice creating and styling a professional financial webpage. The task focuses on using CSS properties to create a clean, organized, and user-friendly banking layout.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Styling
* CSS Box Model
* Flexbox
* Text Styling
* Background Properties
* Border and Border Radius
* Spacing and Alignment
