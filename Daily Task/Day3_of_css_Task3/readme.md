# Day 3 – CSS Task 3: SBI NEFT

## 📌 Project Overview

This is my **Day 3 CSS Task**, created using HTML and CSS.

The webpage is based on an **SBI NEFT (National Electronic Funds Transfer) Interface**, designed to practice creating and styling a banking-related webpage. The task focuses on using CSS properties to create a clean, organized, and user-friendly interface.

* Flexbox
