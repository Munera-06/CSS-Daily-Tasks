# Day 8 – CSS Task 8: Bookhaven

## 📌 Project Overview

This is my **Day 8 CSS Task**, created using HTML and CSS.

The webpage is based on **Bookhaven**, a bookstore and reading-themed webpage designed to showcase books, categories, and book-related information in a clean and attractive layout.

This task focuses on improving my CSS skills by creating a structured webpage and applying different styling techniques such as layouts, typography, colors, spacing, alignment, backgrounds, and image styling.

* HTML5
* CSS3
* CSS Styling
* CSS Box Model
* Flexbox
* Text Styling
* Background Properties
* Image Styling
* Border and Border Radius
* Spacing and Alignment
