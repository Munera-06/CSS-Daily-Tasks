# Day 8 – CSS Task 8: Photo Gallery

## 📌 Project Overview

This project is created as part of the **CSS Daily Tasks – Day 8** practice. The webpage is designed as a **photo gallery** using HTML and CSS.

The main purpose of this task is to practice CSS styling, image arrangement, spacing, alignment, and webpage layout while creating a visually organized photo-based webpage.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Styling
* Image Styling
* Box Model
* Flexbox / Layout
* Background Properties
* Border and Border Radius
* Padding and Margin
* Text Styling
* Width and Height
* Alignment
